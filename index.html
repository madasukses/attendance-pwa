Deploy Guide: Attendance Pro PWA

📋 Overview

Stack: PWA (HTML/CSS/JS) + Google Apps Script + Vercel

  • Frontend: PWA yang bisa diakses via browser & install di home screen
  • Backend: Google Apps Script sebagai serverless backend
  • Database: Google Sheets
  • Hosting: Vercel (free tier)

⚡ Step 1: Setup Google Sheet (5 menit)

Sudah ada: Sheet ID 15p8WVy9ill14D-KXWfbFxlDS3g0uJ_0YJxcswqpbLpg

Struktur kolom (buat di baris pertama):

TanggalWaktu CheckinNamaJabatanLatitudeLongitudeAlamatFotoCatatan

Langkah:

  1. Buka Google Sheet Mas Mada
  2. Pastikan tab bernama Attendance (case-sensitive!)
  3. Buat header di baris 1 sesuai tabel di atas
  4. Jangan hapus/rename tab!

🔧 Step 2: Setup Google Apps Script (10 menit)

2.1 Buka Script Editor

  1. Di Google Sheet, klik Tools → Script editor
  2. Delete kode default (jika ada)
  3. Copy-paste dari file attendance_backend.gs seluruhnya

2.2 Verifikasi Sheet ID

Di kode GAS, pastikan baris ini benar:

javascript
const SHEET_ID = '15p8WVy9ill14D-KXWfbFxlDS3g0uJ_0YJxcswqpbLpg';
const SHEET_NAME = 'Attendance';

2.3 Save

Klik Save (Ctrl+S)

🚀 Step 3: Deploy GAS sebagai Web App (10 menit)

3.1 Deploy

  1. Di Script editor, klik Deploy → New deployment (ikon kotak + ➞)
  2. Pilih Type: Web app
  3. Execute as: Pilih akun Google Mas Mada
  4. Who has access: Pilih Anyone
  5. Klik Deploy

3.2 Copy URL

Muncul modal "New deployment":

  • Copy URL yang panjang (format: https://script.google.com/macros/d/...)
  • Simpan URL ini! Ini yang dipakai di frontend.

3.3 Update Frontend

Di file index.html, baris ~200, ganti:

javascript
const GAS_URL = 'https://script.google.com/macros/d/YOUR_SCRIPT_ID/usercallback';

Jadi:

javascript
const GAS_URL = 'https://script.google.com/macros/d/YOUR_DEPLOYED_URL/usercallback';

Contoh:

javascript
const GAS_URL = 'https://script.google.com/macros/d/AKfycbw1234567890abcdef/usercallback';

🌐 Step 4: Deploy PWA ke Vercel (10 menit)

4.1 Persiapan File

Pastikan Mas Mada punya di folder:

  • index.html
  • manifest.json
  • vercel.json (opsional, tapi recommended)

4.2 Buat vercel.json

Buat file vercel.json di folder yang sama:

json
{
  "buildCommand": "true",
  "outputDirectory": ".",
  "cleanUrls": true,
  "rewrites": [
    {
      "source": "/(.*)",
      "destination": "/index.html"
    }
  ]
}

4.3 Upload ke GitHub

  1. Init git di folder:
bash
   git init
   git add .
   git commit -m "Initial commit: Attendance PWA"
  1. Create repo di GitHub (buat repo kosong: attendance-pwa)
  2. Push:
bash
   git remote add origin https://github.com/[username]/attendance-pwa.git
   git branch -M main
   git push -u origin main

4.4 Deploy via Vercel

  1. Buka vercel.com
  2. Sign in dengan GitHub
  3. Klik Add New → Project
  4. Import repo attendance-pwa
  5. Settings:
    • Framework Preset: Other
    • Root Directory: ./ (default)
  6. Klik Deploy

Tunggu ~1 menit, muncul URL seperti https://attendance-pwa.vercel.app

✅ Step 5: Test (5 menit)

5.1 Test di Browser

Buka: https://attendance-pwa.vercel.app

Harus melihat:

  • ✓ Header "Attendance Pro"
  • ✓ Clock dengan waktu real-time
  • ✓ Location card "Memuat lokasi..."
  • ✓ Form dengan input Nama, Jabatan, Foto, Catatan
  • ✓ Tombol "CHECK IN" hijau

5.2 Test GPS

  1. Izinkan akses GPS saat browser tanya
  2. Lokasi harus berubah dari "Memuat lokasi..." menjadi koordinat

5.3 Test Foto

  1. Klik tombol "📸 Ambil Foto"
  2. Ambil foto (atau pilih dari galeri)
  3. Foto muncul di preview
  4. Tombol berubah jadi "✓ Foto Tersimpan"

5.4 Test Checkin

  1. Isi Nama: "Tes Mada"
  2. Pilih Jabatan: "Manager"
  3. Ambil Foto
  4. Klik CHECK IN
  5. Tunggu 2-3 detik, harus muncul pesan hijau "✓ Checkin berhasil!"

5.5 Verifikasi di Sheet

Buka Google Sheet, harus ada row baru dengan:

  • Tanggal hari ini
  • Waktu checkin
  • Nama "Tes Mada"
  • Jabatan "Manager"
  • GPS koordinat
  • Base64 foto
  • dll

📱 Step 6: Install di Home Screen (Bonus)

Buka PWA di smartphone (vercel URL):

  • iPhone (iOS): Safari → Share → Add to Home Screen
  • Android: Chrome → Menu (3 titik) → Install app

Sekarang bisa buka dari home screen seperti app native! 🎉

🔐 Optional: Setup Authentication

Untuk production, bisa tambah simple login:

javascript
// Di index.html, tambah sebelum form:
const USERNAME = 'mada';
const PASSWORD = 'nosada123';

function checkLogin() {
    const user = prompt('Username:');
    const pass = prompt('Password:');
    
    if (user !== USERNAME || pass !== PASSWORD) {
        alert('Login gagal!');
        location.reload();
    }
}

// Panggil di DOMContentLoaded:
checkLogin();

Tapi untuk tahap awal, bisa skip dulu.

🐛 Troubleshooting

GPS tidak berfungsi?

  • Pastikan browser sudah dikasih akses lokasi
  • Di setting phone, izinkan Chrome/Safari akses Location
  • Coba di outdoor atau tempat dengan sinyal GPS kuat

Checkin tidak masuk Sheet?

  1. Buka GAS Script editor
  2. Klik Execution log (belum ada di toolbar, klik View → Execution log)
  3. Lihat error message
  4. Pastikan Sheet ID dan nama tab benar

Foto tidak disimpan?

  • Base64 string mungkin terlalu besar
  • Gunakan foto resolusi lebih rendah
  • Atau crop/compress sebelum upload

PWA tidak bisa offline?

  • Service Worker belum diimplementasi
  • Untuk tahap awal, buat lebih sederhana dulu
  • Bisa tambah offline support nanti
